# 1. 两数之和（Two Sum）

**难度**：Easy ｜ **Tag**：数组、哈希表

## 题目一句话
给一个数组 `nums` 和目标 `target`，找**两个不同下标**的数使其和为 `target`，返回这两个下标（顺序任意）。

## 核心突破口
"找另一个数"这件事，暴力是 O(n²)；换成**哈希表把"见过的值→下标"记下来**，查找搭档就从 O(n) 降到 O(1)。

## 思路推导（3 步）
1. **暴力**：双层循环枚举所有 `(i, j)`，O(n²) 但稳。
2. **哈希两遍**：第一遍把 `nums[i]→i` 全存进表；第二遍对每 `i` 查 `target-nums[i]` 是否在表，且 `mem[x] != i` 防自匹配。
3. **哈希一遍（最优）**：边走边查——先问"我需要的搭档 `target-nums[i]` 在不在表里？"在就返回，不在就把当前 `(nums[i], i)` 存进去。**先查后存**天然避免自匹配，一趟搞定。

## 复杂度
- 时间：O(n)（一遍遍历，哈希操作均摊 O(1)）
- 空间：O(n)（哈希表最多存 n 个值）

## 一题三问
1. **为什么无序数组不能用双指针？**
   双指针（首尾夹逼）要求数组**有序**，但排序会打乱原始下标，而本题要返回的是**下标**不是值。所以 LC1 只能暴力或哈希。"双指针 Two Sum" 是另一题 **LC 167（有序数组）**。
2. **还能怎么优化？**
   已是最优 O(n)/O(n)；若要求返回**值的组合**而非下标，且数组有序，则可换双指针 O(n) 空间 O(1)。
3. **换个条件会怎样？**
   - 要"三数之和" → LC 15（排序 + 双指针 + 去重，Medium）；
   - 含负数还要"子数组和=K" → LC 560（前缀和 + 哈希，Medium）；
   - 要求返回**所有**满足条件的下标对 → 不能早返回，需收集全部。
