# 1477. 找两个和为目标值且不重叠的子数组

- 难度：Medium
- 标签：滑动窗口 / 前缀和 / 动态规划 / 哈希表
- 日期：2026-09-17

## 题目
给定数组 `arr` 和目标 `target`，找**两个互不重叠**、且**和都等于 target** 的连续子数组，使**长度之和最小**。返回最小总长度；凑不出两个返回 `-1`。

**约束（关键）**：`1 <= arr[i] <= 1000`（全正数）。

## 核心套路
- **全正数** → 滑动窗口找「和为 target 的子数组」。
- **两个不重叠最优配对** → 前缀最优 `best[i]`（= 到下标 i 为止最短合法子数组长度）。
  命中窗口 `[l..r]` 时，用 `best[l-1] + 当前长度` O(1) 配对。

## 关键代码逻辑（记账 / 查账）
- **记账（写）**：`best[r] = min(best[r], len)`
- **查账（读）**：`res = min(res, best[l-1] + len)`

## 复杂度
- 时间：O(n)
- 空间：O(n)

## 一题三问
1. **为什么这样做？** 「先找一个再找一个」非最优且枚举配对 O(n²)；best 前缀最优一遍扫 O(n)。
2. **还能怎么优化？** 时间已最优；可用「前缀最短 + 后缀最短」两遍扫替代，复杂度不变。
3. **换个条件会怎样？** `arr` 含负数 → 滑窗失效（窗口和不单调），改前缀和 + 哈希表（LC 560）。
