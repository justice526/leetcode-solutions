# 387. 字符串中的第一个唯一字符

- 难度：Easy
- 标签：哈希表 / 字符串 / 计数
- 日期：2026-09-17

## 题目
给定一个字符串 `s`，找到**第一个**出现次数**恰好为 1** 的字符，返回其**下标**；如果不存在，返回 `-1`。

## 思路（两遍扫描）
1. 第一遍：用哈希表统计每个字符的出现频次。
2. 第二遍：按原顺序找第一个频次为 1 的字符，返回下标。

## 复杂度
- 时间：O(n)
- 空间：O(k)，k = 字符集大小（小写字母 ≤ 26，可视为 O(1)）

## 一题三问
1. **为什么这样做？** 唯一性 = 频次为 1，必须全局统计后才能按原序取第一个。
2. **还能怎么优化？** 时间已最优 O(n)；字符集固定小时可用定长数组替代字典。
3. **换个条件会怎样？** 要"最后一个唯一字符"就反向扫；字符集很大/含 unicode 就老实 dict。
